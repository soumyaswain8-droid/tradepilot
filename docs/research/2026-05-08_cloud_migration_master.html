The 30-second version

The laptop was never going to be a sustainable platform for an algorithmic trading system run by someone who travels. Cloud isn't an upgrade — it's the only path that addresses the actual constraints: stay-awake-in-backpack, battery, thermal, network, and the SEBI static-IP requirement that's mandatory for real-money Kite Connect trading. The plan below moves to cloud in 3 phases, each one reversible, with the first phase done this weekend.

Three phases at a glance

Why phased Each phase is reversible inside 10 minutes. Phase 1 doesn't risk real money (paper only). Phase 2 builds confidence with no money at stake. Phase 3 is the only phase with regulatory and financial risk — and it's gated by phases 1 and 2 succeeding.

2 · Architecture

Current architecture: launchd + nohup + pgrep on macOS. Cloud target: Docker Compose on AWS Lightsail (Phase 2) with optional ECS Fargate path for Phase 4+ if scale demands it. Kubernetes is overkill for 7 background workers and 1 web app.

State persistence — keep it simple

Current: ~50 MB of JSON files in prototype/data/ and prototype/v*/. Cloud option A (recommended): persistent volume on Lightsail, JSON files keep working. No DB migration. Cloud option B (later, when Phase 4): PostgreSQL for trade history, S3 for ML weights. Don't migrate to DB yet — adds 2 weeks of work for marginal gain at this stage.

Process orchestration

Replace launchd with Docker Compose with restart policies. One docker-compose.yml with the 9 services above. docker compose up -d on Lightsail = full system running. Cron-style scheduled jobs (auto-stop-eod, EOD report, Telegram digest) handled by system cron inside the container — simpler than EventBridge for a one-person team.

4 · Security & Compliance

SEBI compliance · the non-negotiable Individual algo traders are exempt from formal algo registration if trading under 10 orders per second. TradePilot targets 2-4 OPS, so we're inside the exemption. But Zerodha requires static IP whitelisting for any production-grade Kite Connect access — this means real money cannot trade from a laptop with a rotating IP, and not from Render or Railway either. This single requirement determines the cloud provider choice.

Threat model — the top 6

ThreatLikelihoodImpactMitigation
Kite API key leaked via git commitPossibleCriticalDoppler secrets · pre-commit hook · GitHub secret scanning
Flask /api/paper/buy abused without authLikelyMajorJWT on all write endpoints · Flask-Limiter 10 req/min/IP

Cache-poisoning style bug recursLikelyModeratePre-market cache write block · 5-min TTL · all-NaN write rejection
Cloud provider outage during marketUnlikelyMajorFailover to laptop (paper only — real money pauses) · status-page subscription
Bad commit deploys during market hoursPossibleCriticalGitHub Actions: block production deploys 09:15-15:30 IST · canary deploy gate

Critical pre-launch tasks (real-money gate)

  1. Static IP registered with Zerodha — submit Lightsail IP via Kite Connect dashboard, wait 1-2 business days for whitelist confirmation
  2. JWT auth on all write endpoints — Flask-JWT-Extended, 15-min access tokens, 7-day refresh tokens
  3. Doppler secrets management — Kite api_key + api_secret + access_token (rotates daily) · Telegram bot token · Render/AWS credentials
  4. HTTPS-only enforcement — Render auto-provisions, Lightsail needs Let's Encrypt via certbot
  5. Audit log to S3 Glacier — every order decision logged immutably, 5-year retention per SEBI
  6. Rate limiting — Flask-Limiter on all endpoints to prevent abuse and cost spikes
  7. Market-hours deploy block — GitHub Actions check refuses production deploy between 09:15-15:30 IST
  8. Cloudflare in front — DDoS protection · WAF · Rs 1,650/month Pro tier (only needed for Phase 3)

6 · Pre-Flight Checklist

Skills to learn before Saturday morning (~2 hours)

  1. Docker basics — docker build, docker run, docker ps, docker logs. Practice on local machine first.
  2. Reading cloud logs — Render dashboard → Logs tab. AWS Lightsail → SSH + docker logs <service> -f
  3. HTTPS & DNS basics — what an A record does, what a CNAME does, why HTTPS matters
  4. SSH into a VM — ssh -i key.pem ubuntu@<ip> · navigate, view logs, restart services
  5. Reading deployment errors — common ones: missing env var, wrong Python version, port already in use

Pre-flight checklist (do by Friday EOD)

  • Render account created · payment method added (even for free tier — required)
  • GitHub repo public OR Render given access to private repo
  • Local docker build . succeeds against current Dockerfile
  • Local docker compose up brings up Flask + Rust + 7 engines
  • Backup taken of ~/Desktop/TradePilot/ from yesterday — git push to origin too
  • .env.cloud created (a copy of .env with Render-specific paths)
  • Domain purchased (optional but recommended — tradepilot.in or similar at Rs 950)
  • Reviewed this PDF end-to-end · understands the 3 phases · agrees to phase order

Saturday morning — go/no-go gate

  4. You can dedicate the full Saturday — no client calls, no other commitments

7 · The Decision

Option A · Cloud this weekend (recommended)

What: Render free tier · dashboard only · laptop continues running engines.
Risk: Low — pure addition, nothing existing breaks.
Effort: 4-6 hours Saturday.
Outcome: Cloud dashboard reachable from anywhere, validates the migration concept, sets up Phase 2.

Option B · Cloud next weekend

What: Same as A but week of prep first.
Risk: Lower — more time to learn, build confidence.
Effort: 1-2 hours/day this week + 4-6 hours next Saturday.
Outcome: Same as A, just a week later.

Option C · Skip Phase 1, jump to AWS Lightsail next weekend

What: Skip Render · go directly to Lightsail Mumbai.
Risk: Medium — first cloud deploy is also your production deploy. No safety net.
Effort: 8-12 hours over the weekend.
Outcome: Static IP from day 1 · no Render-to-Lightsail re-migration later · costs start at Rs 1,650/mo immediately.

Recommendation: Option A Phase 1 this weekend on Render free. It's the cheapest way to learn that cloud deployment works for your code without risk. Phase 2 next weekend on AWS Lightsail. By 2026-05-19 you have a SEBI-ready cloud system. By 2026-06-08 you can flip to real money. Total elapsed: 31 days. Total cost in those 31 days: Rs 950 (domain) + Rs 0 (Render free) + Rs 825 (half-month Lightsail). About the price of one decent dinner.
