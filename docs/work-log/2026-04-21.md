## 1. Morning — ML model retrain

### Problem diagnosed
Yesterday's Apr 20 retrain produced a broken model:
- `best_iteration = 2` (over-regularized, barely learning)
- `india_vix` importance dropped 9 → 0 (top feature gone)
- Walk-forward IC 0.05 (misleadingly high — model predicting ~0 constant)

### Root causes
1. **Sequential last-10% validation holdout** — landed on April 2026 regime which differed from the 2024–2026 training average. Early stopping fired at iteration 2.
2. **Universe expansion 49 → 199 stocks** without hyperparameter adjustment diluted cross-sectional signal.
3. **Stale hyperparameters** (`reg_alpha=0.5`, `reg_lambda=2.0`) tuned for small Nifty 50 dataset, too aggressive on mixed mid-cap universe.

### Fix (three lines)
`prototype/v4/ml_engine.py`:
- Random train/val split instead of sequential last-10%
- `reg_alpha: 0.5 → 0.3`
- `reg_lambda: 2.0 → 1.0`
- `EARLY_STOPPING_ROUNDS: 50 → 100`

### Result
- `best_iteration = 1,726` (590× deeper learning)
- `india_vix` importance = 3,362 (#1 feature, restored)
- Hit rate 51.8% → 52.2% (40 bps improvement — this is real edge)
- Model size 6.5 KB → 2.4 MB

Archived at: `prototype/v4/models/archive/2026-04-21/`
Pre-fix rollback at: `prototype/v4/models/archive/2026-04-20-pre-fix/`
